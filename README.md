# varn-lang
Varn is an open-source, machine-native programming language and execution runtime designed primarily for AI agents.

Instead of optimizing syntax for human readability, Varn optimizes for deterministic generation, minimal ambiguity, low token cost, strong validation, safe execution, and machine-to-machine program exchange.

Varn programs use a canonical representation with explicit types, effects, capabilities, resource limits and constraints. The goal is to make AI-generated programs cheaper to produce, easier to verify, safer to execute and simpler for other AI systems to inspect and modify.

Humans remain able to inspect and debug Varn through tooling and a human-readable projection, but the canonical language representation is designed for machines first.
